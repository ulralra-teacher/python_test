      채점 항목 (읽기 전용)

        채점 기준은 문구가 아니라 코드(QUESTIONS의 checks)에서 바꿀 수 있어요.

        📥 결과 받을 곳 (구글 시트)

        학생이 📤 결과 제출을 누르면 이 주소로 보내져, 시트에 학생 1명 = 1줄로 엑셀처럼 정리돼요. 입력한 주소는 아래 🚀 학생에게 적용하기를 눌러야 학생들에게도 적용돼요.

        처음 한 번만: 시트 연결 방법 (5분)
        1. 결과를 모을 구글 시트를 열고 확장 프로그램 → Apps Script를 누릅니다.
        2. 기본 코드를 모두 지우고, 아래 코드 복사 버튼으로 복사한 코드를 붙여넣은 뒤 저장(💾)합니다.
        3. 배포 → 새 배포 → 유형: 웹 앱을 고르고, 실행 계정은 나, 액세스 권한은 모든 사용자로 한 뒤 배포합니다. (권한 승인 창이 뜨면 허용)
        4. 나온 웹 앱 URL을 위 주소 칸에 붙여넣고 연결 테스트를 눌러 확인합니다.
        5. 마지막으로 🚀 학생에게 적용하기를 누르면 끝이에요.

        · 코드 맨 위 SPREADSHEET_ID가 결과를 기록할 시트예요. 다른 시트에 모으려면 그 시트의 ID로 바꾸거나 ""(빈 글자)로 두세요. (빈 글자면 Apps Script를 연 그 시트에 기록돼요)
        · 결과는 학생결과(1명 1줄)와 제출기록(제출할 때마다 원본 1줄) 시트에 쌓여요.
        · 액세스 권한에 ‘모든 사용자’가 보이지 않으면(학교 계정 정책) 개인 구글 계정으로 만든 시트에서 진행해 주세요.
        · 코드를 고쳐 다시 배포할 때는 배포 관리 → 수정 → 새 버전으로 해야 주소가 바뀌지 않아요.

        누르면 GitHub에 자동 저장 · 파일을 직접 올릴 필요 없어요
        처음 한 번만 설정 (저장소·토큰)

        토큰 만드는 방법

        1. GitHub 로그인 → 오른쪽 위 프로필 → Settings → 맨 아래 Developer settings
        2. Personal access tokens → Fine-grained tokens → Generate new token
        3. Expiration은 90일 정도로, Repository access는 Only select repositories에서 이 저장소만 고릅니다.
        4. Permissions → Repository permissions → Contents를 Read and write로 바꿉니다.
        5. Generate token 후 나온 github_pat_… 글자를 위 토큰 칸에 붙여넣고 설정 저장을 누릅니다. (토큰은 이 화면에서만 보이니 한 번 복사해 두세요)
